# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting:
**Security > Report a vulnerability** on the
[repository page](https://github.com/alanmatiasdev/scopeview/security/advisories/new).

Include the version, your operating system, and steps to reproduce. You will get a reply as soon
as possible, and the fix will be released with credit to you unless you prefer otherwise.
